## Run locally

Install Python and extract this ZIP. Open a terminal in the extracted folder and run:

```text
pip install -r requirements.txt
```

Open the desired experiment folder and run its Python file as described in its README.

## Upload to GitHub

1. Extract this ZIP.
2. Create an empty repository in your GitHub account.
3. Choose **uploading an existing file** or **Add file > Upload files**.
4. Drag all extracted experiment folders and root files into the upload area, then commit the changes.

Upload the extracted contents so GitHub displays the README, code, and graphs directly.
